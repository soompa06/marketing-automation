# 📊 월간보고서 자동 생성 가이드

## 핵심 동작 원리

매달 말 작성하셨던 워드 보고서를 자동화합니다.

**기준은 "검수 시점"이 아니라 "포스트 작성일자"입니다.**
- 4월에 1월에 쓴 글을 검수했어도 → **1월 보고서**에 들어감
- 5월에 4월에 쓴 글을 검수해도 → **4월 보고서**에 들어감

---

## 워크플로우 (4단계 자동 진행)

```
[1] output/check_results_*.csv 모두 로드 (검수 시점 무관)
    ↓
[2] 각 블로그 포스트의 제목·작성일자 자동 추출
    └─ 캐시 사용 (.blog_meta_cache.json) — 같은 URL 재추출 안 함
    ↓
[3] 포스트 작성월이 보고 대상인 글만 필터링
    ↓
[4] 가게별 또는 블로거별로 그룹핑 → 워드 파일 생성
```

---

## 사용법

### 가장 흔한 케이스 — 이번 달, 모든 가게
```bash
python src/monthly_report/generate.py
```

### 특정 월
```bash
python src/monthly_report/generate.py --year 2026 --month 4
```

### 블로거 단위 보고서 (한 블로거에 1개 보고서)
```bash
python src/monthly_report/generate.py --scope blogger
```

### 특정 가게만
```bash
python src/monthly_report/generate.py --scope business --name 가게A
```

### 특정 블로거만
```bash
python src/monthly_report/generate.py --scope blogger --name "가게A_홍길동"
```

### 가게 블로그 URL을 표지에 표시하려면
`config/businesses.csv`를 만들고:

```csv
name,blog_url
가게A,https://blog.naver.com/example-store-a
가게B,https://blog.naver.com/example-store-b
루카네일,https://blog.naver.com/ruca41
```

```bash
python src/monthly_report/generate.py --blog-urls config/businesses.csv
```

### 빠른 모드 (메타 추출 스킵)
제목/작성일자 자동 추출이 너무 느리거나 인터넷 안 될 때:
```bash
python src/monthly_report/generate.py --no-meta
```
→ 이 경우 작성월 필터링이 안 되므로 **모든 검수 결과가 나옴**

### 디버그 모드 (브라우저 보면서)
```bash
python src/monthly_report/generate.py --show-browser
```

## 작성월에 글이 없을 때

해당 월에 작성된 글이 없으면 **친절한 디버그 정보**를 보여줍니다:

```
⚠️  2026년 5월에 작성된 블로그 글이 없습니다.

   현재 데이터의 작성월 분포:
      2026년 3월: 1건
      2026년 4월: 11건
      (작성일 추출 실패): 2건
```

이걸 보고 원하는 월로 다시 실행하시면 됩니다.

---

## 메타정보 캐시 시스템

같은 블로그 URL은 **한 번만** 추출하고, 결과를 `output/.blog_meta_cache.json`에 저장합니다.

장점:
- 보고서를 여러 번 다시 만들어도 빠름
- 가게별 보고서 → 블로거별 보고서 다시 돌려도 메타 추출 재사용
- 한 달간 누적된 100명+ 데이터도 첫 실행 후엔 즉시 처리

캐시 초기화하고 싶으면:
```bash
rm output/.blog_meta_cache.json
```

```

├── check_results_*.csv       ← 1순위 도구가 만드는 검수 결과

└── reports/                  ← 월간보고서 출력 위치

    ├── 가게B_2026년_04월_월간보고서.docx
    └── ...
```

## 향후 확장 가능 항목

요청 사항 중 하나였던 **구글 시트 직접 연동**은 아직 미구현입니다.

현재는 1순위에서 만든 CSV → 자동 처리되는 흐름인데,
구글 시트에서 직접 데이터를 가져오시고 싶다면:
- 구글 시트 API 연동 추가 가능
- 시트 구조에 맞춰 추가 컬럼(블로거 이름, 캠페인 등) 매핑 필요

구글 시트의 어떤 컬럼들을 활용하시는지 알려주시면 그에 맞게 구현해드릴게요.
