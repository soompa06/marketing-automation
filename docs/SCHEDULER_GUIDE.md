# ⏰ 자동 스케줄 — 사용법 가이드

매일/매주 정해진 시각에 검수, 블덱스 시트 분류, 사용자 지정 명령을 자동 실행할 수 있어요.

---

## 1. 어떻게 동작하나요?

```
┌──────────────────────────────┐         ┌─────────────────────┐
│  자동 스케줄 페이지에서 등록  │ writes  │  scheduled_jobs.json │
│  (UI 폼 또는 직접 JSON 편집)  │ ──────► │  (작업 정의)         │
└──────────────────────────────┘         └──────────┬──────────┘
                                                     │ 60초마다 reload
                                                     ▼
                                         ┌─────────────────────┐
                                         │  스케줄러 데몬       │
                                         │  (runner.py 백그라운드)│
                                         └──────────┬──────────┘
                                                     │ 정해진 시각에
                                                     ▼
                                         ┌─────────────────────┐
                                         │  실행 (subprocess) + │
                                         │  로그 자동 저장      │
                                         └─────────────────────┘
```

- **데몬이 떠 있어야** 자동 실행이 됩니다
- **본인 PC가 켜져 있어야** 데몬이 살아있습니다 (절전 모드 OFF 권장)
- 데몬은 `output/.scheduler/{job_id}_{timestamp}.log`에 실행 로그를 남김

---

## 2. 첫 사용 — 단계별

### 2.1 데몬 시작

1. 좌측 사이드바 **⏰ 자동 스케줄** 메뉴
2. 페이지 상단 **▶️ 데몬 시작** 버튼 클릭
3. "✅ 데몬 실행 중" 메시지 확인

> 데몬은 백그라운드 작업으로 떠 있어요. Streamlit 앱이 꺼져도 데몬은 계속 돌지만,
> PC가 꺼지거나 잠자기로 들어가면 멈춥니다.

### 2.2 작업 추가

스크롤을 내려서 **➕ 새 자동 작업 추가** 폼에서:

| 입력 | 의미 |
|---|---|
| 작업 이름 | "매일 아침 식당 시트 자동 분류" 등 자유롭게 |
| 어떤 작업? | 아래 [작업 종류] 표 참고 |
| 언제? | daily / weekly / hourly / N분마다 |
| 파라미터 | 선택한 작업 종류에 따라 다름 |
| 시간 | 09:00 같은 형식 |

**➕ 작업 추가** 클릭 → 60초 안에 데몬이 자동 반영합니다.

### 2.3 즉시 실행 (테스트)

작업이 정해진 시간 전이라도 **▶️ 지금 실행** 버튼으로 한 번 돌려볼 수 있어요.

---

## 3. 작업 종류

### 3.1 `blogdex_pipeline` — 블덱스 시트 자동 분류

`src/blogdex/sheet_pipeline.py` 실행. 등록된 캠페인의 시트에서 '지수' 빈 행을 찾아 블덱스 조회 후
자격자/미달자를 자동 분류합니다.

⚠️ **본인 PC가 깨어있을 때만** 작동합니다 (블덱스는 NAS·헤드리스 환경에서 Cloudflare에 차단됨).

파라미터:
- 처리할 캠페인: 다중 선택 (예: restaurant, skin)
- Dry run: 실제 시트 변경 없이 미리보기만

### 3.2 `naver_check` — 네이버 노출 일괄 검수

CSV에 적힌 블로거 목록을 일괄 검수.

파라미터:
- 입력 CSV 경로 (PROJECT_ROOT 기준 상대 또는 절대경로)

### 3.3 `custom_command` — 사용자 지정 명령어

임의의 명령어를 그대로 실행 (백업 자동화, 임의 스크립트 등).

파라미터:
- 실행할 명령어
- shell로 실행: 파이프(`|`)·리다이렉트(`>`) 사용 시 체크

---

## 4. 시간 설정 옵션

| 종류 | 입력 | 예 |
|---|---|---|
| `daily` | 시:분 | 매일 09:00 |
| `weekly` | 요일 + 시:분 | 매주 mon 09:00 |
| `hourly` | 분 | 매시 :00 (정각마다) |
| `every` | N + 단위 | 30 minutes / 2 hours |

---

## 5. 일상적인 사용 흐름 (추천 시나리오)

> **사용자의 일상 자동화 예시**

| 시각 | 작업 | 종류 |
|---|---|---|
| 매일 09:00 | 식당 + 피부과 시트 신청자 자동 분류 | `blogdex_pipeline` (campaigns: [restaurant, skin]) |
| 매일 18:00 | 오늘 받은 블로그 글 일괄 검수 | `naver_check` (input_csv: today's CSV) |
| 매주 mon 10:00 | 백업 zip 자동 생성 | `custom_command` (백업 명령) |

## 6. 데몬 관리

### 6.1 데몬이 살아있는지 확인

자동 스케줄 페이지 상단:
- **🟢 데몬 실행 중** → OK
- **⚠️ 실행되고 있지 않음** → ▶️ 데몬 시작 버튼 클릭

### 6.2 데몬 로그 보기

페이지 상단 **📺 데몬 로그 (최근 30줄)** 열기.

각 작업의 상세 실행 로그는 `output/.scheduler/{job_id}_{날짜시간}.log`에 자동 저장됩니다.

### 6.3 데몬 중지

페이지 상단 **🛑 데몬 중지** 버튼.
⚠️ 중지하면 자동 실행이 멈춥니다 (수동 ▶️ 지금 실행은 그대로 가능).

### 6.4 PC 재부팅 후

데몬은 자동으로 다시 뜨지 않습니다. 재부팅 후 자동 스케줄 페이지에서 다시 ▶️ 데몬 시작.

> 자동으로 띄우고 싶으면:
> - **macOS**: `launchd` plist 작성 (advanced)
> - **NAS/Linux**: Docker 컨테이너 (`deploy/docker-compose.yml`이 영구 실행을 보장)
> - **Windows**: 작업 스케줄러 또는 시작프로그램 등록

## 7. 작업 정의 파일 직접 편집

UI에서 등록한 모든 작업은 다음 파일에 저장됩니다:

```
config/scheduled_jobs.json
```

VS Code 등 텍스트 에디터로 직접 편집해도 됩니다. 데몬이 60초 안에 자동 reload.

예시 형식:

```json
[
  {
    "id": "abc12345",
    "name": "매일 아침 식당 시트 분류",
    "type": "blogdex_pipeline",
    "params": {
      "campaigns": ["restaurant"],
      "dry_run": false
    },
    "schedule": {"kind": "daily", "time": "09:00"},
    "enabled": true,
    "last_run": null,
    "last_status": null,
    "created_at": "2026-05-06T22:00:00"
  }
]
```

## 8. 트러블슈팅

| 증상 | 원인 / 해결 |
|---|---|
| 데몬 시작 후 바로 꺼짐 | `output/.jobs/스케줄러_*.log` 확인. `schedule` 라이브러리가 미설치면 `pip install schedule` |
| 작업이 정해진 시각에 안 돔 | 1) 데몬이 살아있는지 2) PC가 절전 모드 들어가지 않았는지 3) `enabled: true`인지 |
| 블덱스 작업이 항상 실패 | 블덱스 세션이 만료됐을 가능성. **블덱스 로그인** 다시 진행 |
| 시트 작업이 권한 오류 | 서비스 계정 이메일이 시트에 편집자로 공유됐는지, 또는 OAuth 토큰이 유효한지 확인 |
| `last_status: failed` | 해당 작업의 ▶️ 지금 실행으로 한 번 돌리고 콘솔/로그에서 정확한 에러 확인 |

---

## 9. CLI로 직접 실행

UI 없이 터미널에서도 가능:

```bash
# 등록된 작업 목록
python src/scheduler/runner.py --list

# 모든 활성 작업을 즉시 1회 실행 (테스트용)
python src/scheduler/runner.py --once

# 특정 작업 즉시 실행
python src/scheduler/runner.py --run <job_id>

# 데몬 모드 (포그라운드)
python src/scheduler/runner.py
```
